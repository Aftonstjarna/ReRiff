# Gamepad prompt glyphs

Derived from the MIT-licensed **Gamepad Prompt Asset Pack** by Al. Lopez.
The selected source
SVGs are in `svg/`; `png/` contains 64x64 transparent renditions used by the
launcher's gamepad binding badges.

`prompts.bmp` is a generated 8-column sprite sheet. The glyph order is:

```text
a b x y dpad_up dpad_down dpad_left dpad_right
lb rb lt rt ls ls_up ls_down ls_left
ls_right l3 rs rs_up rs_down rs_left
rs_right r3 start back guide misc
p1 p2 p3 p4 touchpad
```
